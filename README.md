# Must-Have That

The feeder where every That App Studio must-have lives and can be seen.

Same shape as the FAQ app and Wanna Do That. Things feed in. One place shows them. In the Briefcase CMS this is a custom post type, beside posts and post formats.

A must-have is not a wish. An app is not finished until every must-have below has a receipt.

## The must-haves

1. **REST-native (TS-CORE-072).** Every app exposes a REST API out of the box. The CLI consumes that API. It is not a second system.
2. **ClarifyThat (TS-CORE-020).** Everything produced passes ClarifyThat before it is finished.
3. **Egg method.** Written from the ground up with the semantic node framework and the Gift Egg. Bootstrap English micro-slices, then the Bootstrap Engine Manifest, then a Runtime Egg before anything is hosted.
4. **Bootstrap manifest micro-slice.** Python and Rust are the output languages. Bootstrap English is the ticket language.
5. **Equity and smooth road.** Four of four before a mutation. No stage starts on a broken road.
